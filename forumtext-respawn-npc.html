Hello again,

from the maker of Respawn Chest and Repair Chest comes another plugin for one of those quiet admin chores that never quite go away.

You place a nice NPC at spawn. Someone kills it. You place it again. Repeat until you question your life choices.


Respawn NPC takes care of exactly that.

Register an NPC once: the plugin stores a snapshot of its looks and gear, plus the spawn pose from where you stood when registering. After it dies, a timer starts. When the timer expires, a new copy is spawned at that saved pose -- not at the corpse, not at death location.


Optional: set a guard post. Shortly after spawn the NPC walks there, faces the saved direction, and locks. If it wanders off later, it is sent back. If it enters combat, the walk waits until the fight is over.


Players do not need to install anything. Respawn itself is silent -- no chat spam.

The plugin stays out of the way when nothing is pending: timers and guard checks only run while there is work to do.

NPC einmal registrieren: Das Plugin speichert einen Snapshot von Aussehen und Ausrüstung sowie die Spawn-Pose von dem Ort, an dem ihr beim Registrieren gestanden habt. Nach dem Tod startet ein Timer. Nach Ablauf spawnt eine neue Kopie an dieser gespeicherten Pose -- nicht am Leichnam, nicht am Todesort.


Optional: einen Wachposten setzen. Kurz nach dem Spawn läuft der NPC dorthin, dreht sich in die gespeicherte Blickrichtung und locked. Wandert er später ab, wird er zurückgeschickt. Kommt er in den Kampf, wartet der Lauf, bis der Kampf vorbei ist.


Spieler müssen nichts installieren. Der Respawn selbst ist still -- kein Chat-Spam.

Das Plugin hält sich zurück, wenn nichts ansteht: Timer und Guard-Checks laufen nur, solange es etwas zu tun gibt.

How it works

  • Stand at the desired respawn spot and face the direction you want
  • Look at an NPC, or stand close if it is roaming (within 10 blocks)
  • Use [tt]/make-respawn <minutes>[/tt] in chat
  • That NPC dies
  • A one-shot timer starts
  • The world keeps turning
  • When the timer expires, a new NPC is spawned at the saved pose and the snapshot is applied
  • Optional: if a guard post is set, the NPC walks there shortly after spawn and locks facing on arrival


The snapshot is taken at register / update time, never on death.

While a timer is already running, further deaths do not restart or extend it.

This is not a perfect clone: every readable field is stored, but only fields with setters are restored. Secondary hand item and pregnancy are saved for later API versions and ignored on spawn.

So funktioniert es

  • Am gewünschten Respawn-Ort stehen und in die gewünschte Richtung schauen
  • NPC anschauen, oder nah ranstellen wenn er umherläuft (innerhalb von 10 Blöcken)
  • [tt]/make-respawn <minutes>[/tt] im Chat eingeben
  • Der NPC stirbt
  • Ein einmaliger Timer startet
  • Die Welt dreht sich weiter
  • Nach Ablauf spawnt ein neuer NPC an der gespeicherten Pose und der Snapshot wird angewendet
  • Optional: Ist ein Wachposten gesetzt, läuft der NPC kurz nach dem Spawn dorthin und locked die Blickrichtung bei Ankunft


Der Snapshot wird beim Registrieren / Updaten genommen, nie beim Tod.

Läuft bereits ein Timer, wird er durch weitere Tode weder neu gestartet noch verlängert.

Das ist kein perfekter Klon: Jedes lesbare Feld wird gespeichert, aber nur Felder mit Settern werden wiederhergestellt. Item in der Nebenhand und Schwangerschaft werden für spätere API-Versionen mitgespeichert und beim Spawn ignoriert.

Commands

Only server admins listed in Server_Admins in server.properties can use these commands.

Target the NPC first (look at it, or stand nearby), except for [tt]/respawn-list[/tt] and the optional [tt]#id[/tt] forms.

  • /make-respawn <minutes> - registers the target NPC. Snapshot = NPC state; your pose = spawn. Already registered: error (use /respawn-update)
  • /respawn-update - refreshes the NPC snapshot only (spawn pose stays)
  • /respawn-update pose - updates spawn pose only (your position/rotation)
  • /respawn-update all - snapshot + spawn pose
  • /respawn-update timer <minutes> - interval only
  • /respawn-update #2 ... - same modes, target by respawn id (no line of sight needed)
  • /respawn-now [#id] - spawn immediately; if the old body is still alive, it is deleted after a successful spawn
  • /respawn-remove [#id] - unregisters; the living NPC stays
  • /respawn-info [#id] - interval, pending state, remaining time, spawn/current position
  • /respawn-list - list all registered NPCs
  • /respawn-list timer - list active guard checks
  • /make-guard <id> - guard post = your position (+ rotation); NPC walks there after spawn
  • /guard-remove <id> - clear guard post; NPC stays put


A value of 0 minutes uses a short test delay.

Maximum respawn time: 24 hours.

Transient NPCs cannot be registered.

Guard post is independent of spawn pose: [tt]/respawn-update pose[/tt] does not change it.

Tip: For stationary guards, set the NPC to defensive/aggressive (and use a guard post). Roaming AI otherwise keeps them wandering until they arrive and lock.

Befehle

Nur Server-Admins aus Server_Admins in server.properties können diese Befehle verwenden.

NPC zuerst anvisieren (anschauen oder nah ranstellen), außer bei [tt]/respawn-list[/tt] und den optionalen [tt]#id[/tt]-Formen.

  • /make-respawn <minutes> - registriert den anvisierten NPC. Snapshot = NPC-Zustand; eure Pose = Spawn. Bereits registriert: Fehler (dann /respawn-update)
  • /respawn-update - aktualisiert nur den Snapshot (Spawn-Pose bleibt)
  • /respawn-update pose - aktualisiert nur die Spawn-Pose (eure Position/Rotation)
  • /respawn-update all - Snapshot + Spawn-Pose
  • /respawn-update timer <minutes> - nur Intervall
  • /respawn-update #2 ... - dieselben Modi, Ziel über Respawn-ID (keine Sichtlinie nötig)
  • /respawn-now [#id] - sofort spawnen; lebt der alte Körper noch, wird er nach erfolgreichem Spawn gelöscht
  • /respawn-remove [#id] - deregistriert; der lebende NPC bleibt
  • /respawn-info [#id] - Intervall, Pending-Status, Restzeit, Spawn-/aktuelle Position
  • /respawn-list - listet alle registrierten NPCs
  • /respawn-list timer - listet aktive Guard-Checks
  • /make-guard <id> - Wachposten = eure Position (+ Rotation); NPC läuft nach dem Spawn dorthin
  • /guard-remove <id> - Wachposten entfernen; NPC bleibt stehen


0 Minuten entsprechen einem kurzen Test-Delay.

Maximale Respawn-Zeit: 24 Stunden.

Transient NPCs können nicht registriert werden.

Der Wachposten ist unabhängig von der Spawn-Pose: [tt]/respawn-update pose[/tt] ändert ihn nicht.

Tipp: Für stehende Wächter den NPC auf defensive/aggressive stellen (und einen Wachposten setzen). Sonst wandert die normale KI weiter, bis sie ankommt und locked.

Download / Installation

Respawn NPC - Latest Release

Place the JAR here:

[tt]./plugins/RespawnNpc/RespawnNpc.jar[/tt]

Restart the server afterwards.

State is stored per world as [tt]Plugins/RespawnNpc/<WorldName>.db[/tt].
